# Project Instructions

Project: Selective Hierarchical Memory for Faithful Explainable NPC Decision-Making in Persistent Game Worlds

- Use Python.
- Core logic must work without an LLM.
- LLMs must never directly mutate world state.
- Every NPC action must pass the valid-action layer.
- Important decisions must create a decision trace.
- Explanations must use actual decision factors.
- Keep research-critical logic deterministic and testable.
- Add tests for changes.
